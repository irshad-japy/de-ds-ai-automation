# Observability checklist

Capture these values/screenshots for the final demo:

- [ ] Latest batch status and row count.
- [ ] Stream freshness: newest shipment event timestamp.
- [ ] Document extraction success: invoice result JSON exists / portal shows successful call.
- [ ] Search latency: query completes and returns the expected source.
- [ ] Agent/model latency: Foundry trace or app request duration.
- [ ] Tool failure count: malformed event drill or App Insights exception count.
- [ ] Cost check: Cost Management / resource list reviewed before cleanup.
