# Model card — shipment delay risk

## Intended use
Predict the probability that a synthetic shipment is delayed. The output `risk_score` is the estimated probability for class `is_delayed=1`.

## Not intended for
This demonstration must not be used for consequential logistics or customer decisions without real-data validation, fairness review, calibration review, security controls, and production monitoring.

## Training data
Synthetic shipment rows generated by `python -m ml.generate_data`. The training script logs a SHA-256 dataset fingerprint and the exact feature list with each MLflow run.

## Candidate models
1. Logistic regression baseline.
2. Random forest tree-based model.

The selected model is the candidate with the highest validation ROC AUC; F1 is the tie-breaker.

## Registry metadata
`python -m ml.register_model --tracking azure` adds model version tags for validation ROC AUC, F1, dataset SHA-256, code version, and limitations.

## Limitations
- Synthetic relationships do not represent real carrier behavior.
- Correlation/prediction is not causation.
- A high `risk_score` does not prove why a shipment will be delayed.
- Data freshness and feature drift must be monitored.
