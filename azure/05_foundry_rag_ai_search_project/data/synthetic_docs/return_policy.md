# Returns and Damaged Items Policy

Customers may return unopened standard products within 30 calendar days of delivery. Damaged or defective items must be reported within 14 calendar days of delivery. After the damage report is accepted, the customer has 21 calendar days to send the damaged item back using the provided return label. Approved damaged-item returns are eligible for replacement or refund after inspection. Custom-built items are not eligible for normal change-of-mind returns unless they arrive damaged or defective.
