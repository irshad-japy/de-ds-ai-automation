# Product Warranty Policy

Standard hardware products include a 12-month limited warranty from the delivery date. The warranty covers manufacturing defects under normal use. Consumables have a 90-day warranty. Accidental damage, unauthorized repair, misuse, and normal cosmetic wear are excluded. Warranty claims require the order number and a description of the fault.
